# World Packs

A world pack is a folder or `.zip` holding a world's **content only**: `pack.json` (manifest: `formatVersion`, `name`, `description`, `author`, per-collection counts) plus `world/<collection>/<file>.json`. Accounts, characters, guilds and owners never travel in a pack. Because content is plain schema-versioned JSON ([content pipeline](/content/content_pipeline.md)), packs are diffable and can be generated by scripts or agents.

## Export
`WorldPack.export(worldDir, out, name, ...)` loads the world, runs the full `ContentValidator`, and **refuses to export a world with errors** (warnings are fine). A `.zip` target is byte-reproducible (sorted entries, fixed timestamps); anything else is written as a new or empty folder.

## Import
`WorldPack.import(pack, targetWorldDir, mode)`:
1. Reads the pack with strict rules: only `pack.json` and paths matching `world/<known collection>/<safe name>.json` are accepted (no `..`, no nesting, no other file types); per-entry (8 MB), entry-count (20,000) and total (256 MB) limits; unsupported `formatVersion` is rejected.
2. Builds the result in a **staging folder** next to the target (for `MERGE`, a copy of the existing world plus the pack's files) and runs full validation on it.
3. Only if valid, swaps it in. Previously existing content is moved to `<target>.bak-<millis>` rather than deleted; on any failure the staging folder is removed and the target is untouched.

Modes (`PackImportMode`): `NEW_ONLY` (default; refuses if the target already has content), `MERGE` (same file names overwritten, the rest kept), `REPLACE` (whole world replaced, old one backed up).

Import is an offline operation: stop a running server first, or let its [content watcher](/content/hot_reload.md) pick up the change (a swapped directory may need a restart).

## Commands
```powershell
.\gradlew.bat :server-app:exportWorldPack -PcontentArgs="--out packs/mine.zip --name MyWorld --author Me"
.\gradlew.bat :server-app:importWorldPack -PcontentArgs="--file packs/mine.zip --dir server-data/world --mode merge"
```
Exit code 0 on success, 1 on validation or pack errors (the issues are printed), 2 on bad arguments. Not yet supported: exporting a *slice* of a world (selected maps plus their dependencies). See also [world library](/server/world_library.md), which can create a world directly from a pack.
