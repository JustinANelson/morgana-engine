Build online RPGs
while standing in them.

Morgana is a cross-platform 2D engine on Kotlin and LibGDX for online RPGs and co-op dungeon crawlers. One client core runs on desktop, Android and the browser. A game is just data and sandboxed Lua.

What you get

The spirit of Mirage Source and Player Worlds (simple to run, easy to host yourself) with a modern, testable core.

Live F1 editors

Press F1 in-game to edit maps, dungeon floor recipes, items, NPCs and bosses, spells, shops, quests, events, animations, classes, game rules and more, without a restart.

Deterministic core

A pure Kotlin simulation at 20 ticks per second with seeded RNG, so results are reproducible and easy to test.

Data first

Every piece of content is a schema-validated JSON file. Author it in the GUI, a text editor, Tiled or scripts; it all goes through one validation and hot-reload pipeline.

Roguelike dungeons

Procedural floors (rooms and corridors, caves, BSP, open arena), instanced co-op runs, configurable permadeath, extraction runs, boons, skill trees and random loot affixes.

Realtime and action combat

Combos, hitboxes, dodge i-frames, piercing projectiles and ground-targeted AoEs, alongside parties, guilds, trading and page-based quests.

Engine and game are separate

The engine knows no particular game. Attributes, formulas, loot and rules live in a game folder, and a boundary test enforces the split.

Edit the world you're standing in

The first account on a server becomes Owner. Press F1 and a full editor suite opens over the live game: paint tiles on layered maps, place NPC spawns, tune items and spells, then save. Changes go through the same validation as hand-edited JSON.

  • Layered tile painting with undo, zoom and attributes
  • Dockable, resizable panels and saved layouts
  • Never GUI-only: everything it makes is plain JSON on disk

Plugins describe UI, the client draws it

Server plugins and Lua scripts declare windows as data, and the standard client renders them identically on every platform. The welcome window here was described by a server plugin.

  • Minimap, chat channels, hotbar and window system built in
  • Inventory, equipment, character and world map panels

Play anywhere

The same client core compiles to JavaScript for the browser, with touch controls and a phone layout, and ships as an Android APK. A browser build can be published straight to itch.io.

  • Desktop: LibGDX on the JVM
  • Browser: TeaVM, served by the game server or hosted statically
  • Android: debug APK from one Gradle task

Architecture

Four layers with strict seams. Optional features are systems that plug into the kernel; nothing else reaches in.

CorePure deterministic rules and the 20 TPS simulation. No I/O, networking, persistence or rendering.
SystemsOptional gameplay features installed by the simulation through kernel seams. A genre is a tag on systems, never a layer.
TemplatesStarting games and content you can copy and reshape.
PluginsServer extensions and sandboxed Lua scripts for per-game behaviour.
ModuleRole
core-domainPure rules, simulation, content validation
shared-protocolClient and server packets and codecs
server-persistenceJSON document store, content loader, schema export
server-appNetty server, hot reload, content CLI
client-coreLibGDX renderer, HUD, F1 editors, net client
script-luakSandboxed Lua runtime
client-desktop · client-android · client-webPlatform launchers around the shared client core

A game is a folder

No engine changes needed to make a new game. Scaffold one, then edit it directly in a text editor or in the F1 editors.

# games/my-game
game.json      # rules, attributes, formulas
data/          # schema-versioned JSON content
assets/        # your art and audio
scripts/       # sandboxed Lua

The repo ships several games to learn from:

  • blank and tutorial-village: minimal starting points
  • roguelike: the Ashen Keep co-op dungeon crawler template
  • white-river: a larger world

Get started

Needs Java 17+. On macOS or Linux use ./gradlew instead of .\gradlew.bat.

No code: use the GUI 
.\gradlew.bat :client-desktop:run
Open Local Worlds, run the New Realm Wizard, press Play, then press F1.
Or scaffold a game and run a dedicated server 
.\gradlew.bat :server-app:newGame -PcontentArgs="--name 'My Game' --dir games/my-game"
.\gradlew.bat :server-app:run --args="--game games/my-game"
.\gradlew.bat :client-desktop:run
Verify everything 
.\gradlew.bat check
Runs unit and integration tests, schema drift and module-boundary checks, and the wiki lint.
